# PZ-A7200T-KFB에서 사용

검증한 조합은 `ORYUKDO-KFB-TLB8-20261108.bit`와 `ORYUKDO-KFB-clocksource-trace-v2.img`이다. 파일은 [Release 첨부 파일](https://github.com/VARZero/ORYUKDO-3d5i_BOSIO_SoC/releases/tag/board-20261108-tlb8-trace-v2)로 제공한다. 로컬 패키지에서는 `artifacts/`에 보관한다. 두 파일의 SHA256은 `provenance/artifacts.json`에 있다.

1. balenaEtcher에서 `.img`를 선택하고 대상 microSD를 확인한 뒤 기록·검증한다. 대상 카드 내용은 덮어쓴다. 이미지 파일을 파일시스템에 복사하는 방식이 아니다.
2. 보드 전원을 끈 상태에서 온보드 TF 슬롯에 카드를 넣는다. SDHC/SDXC를 사용하며 SDSC는 로더에서 거부한다.
3. JTAG와 USB UART를 연결하고 전원을 켠다. Vivado Hardware Manager에서 `xc7a200t` 장치에 위 `.bit`를 Program Device로 올린다.
4. UART를 115200 baud, 8N1, 흐름 제어 없음으로 연다. 실제 시험에서는 COM4였지만 다른 컴퓨터에서는 포트 번호를 확인한다.
5. OpenSBI 배너, Linux 초기화 로그, `oryukdo#` 프롬프트를 확인한다.

JTAG 프로그램은 휘발성이다. 전원을 끄면 다시 올려야 하며 이번 작업은 구성 Flash를 기록하지 않았다. 하나의 UART 포트는 한 터미널에서만 연다.

쉘에서 다음을 확인할 수 있다.

```sh
cat /proc/cpuinfo
uname -a
grep MemTotal /proc/meminfo
echo $((19+23))
ddrcheck
```

실제 검사에서 산술 결과 42, 커널 버전 `6.12.0-oryukdo-kfb`, MemTotal `1024148 kB`, `DDR_HIGH_OK pages=16`을 확인했다. 메모리 숫자는 예약 영역을 제외한 값이며 1GiB 칩 용량과 다르게 보이는 것이 정상이다.

SD는 현재 부트 전용이다. Linux 루트 파일시스템은 Image 안의 initramfs이고 SD 파일 저장은 지원하지 않는다. 전원 종료 후 파일을 보존하려면 런타임 SD 컨트롤러·드라이버·파일시스템을 추가해야 한다.

HDMI 케이블을 연결한다고 Linux 데스크톱이 자동 출력되지는 않는다. 현재 표시 경로에는 BOSIO를 구동하고 완성된 프레임을 넘기는 SW가 필요하다. 추가 AXI UART·SPI·I2C도 현재 DT에 장치로 등록하지 않았으므로 자동으로 Linux 장치 파일이 생기지 않는다.

## 주요 핀

| 신호 | FPGA 핀 |
|---|---|
| SD CLK / MOSI / MISO / CS | B20 / E17 / A20 / A21 |
| 기본 UART | V18 / V19, 방향은 XDC 참조 |
| 추가 UART TX / RX | Y16 / AA16 |
| 추가 SPI SCK / MOSI / MISO / CS | W15 / W16 / AB16 / AB17 |
| 추가 I2C SCL / SDA | W14 / Y14 |
| 센서 I2C SCL / SDA | AA15 / AB15 |
| HDMI2 clock ± | E19 / D19 |
| HDMI2 data0 ± / data1 ± / data2 ± | F13/F14 / E13/E14 / C18/C19 |

I2C 외부 모듈에는 적절한 풀업이 필요하다. 제공된 핀 제약을 기준으로 연결하고 보드 모델과 커넥터 방향을 확인한다.
