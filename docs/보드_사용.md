# PZ-A7200T-KFB 사용과 실보드 확인

## 먼저 구성 선택

| 구성 | 비트스트림 / SD 이미지 | 상태 |
|---|---|---|
| 현재 SD4·DMA 후보 | `ORYUKDO-KFB-SD4-DMA-v1.bit` / `ORYUKDO-KFB-SD4-DMA-v1.img` | 로컬 기능 검증·전체 보드 배선 완료, 실보드 MMC/ext4 검증 전 |
| 이전 trace-v2 기준본 | `ORYUKDO-KFB-TLB8-20261108.bit` / `ORYUKDO-KFB-clocksource-trace-v2.img` | 2026-11-08 실보드 UART 셸 확인, SPI 부팅 전용 |

[현재 후보 다운로드](https://github.com/VARZero/ORYUKDO-3d5i_BOSIO_SoC/releases/tag/sd4-dma-20261110-candidate)와
[이전 기준본 다운로드](https://github.com/VARZero/ORYUKDO-3d5i_BOSIO_SoC/releases/tag/board-20261108-tlb8-trace-v2)를 구분한다.
각 릴리스의 checksum 파일로 검사하고 `.bit`와 `.img`를 같은 구성끼리 사용한다.
아래 SD4 절차는 앞으로 수행할 확인 절차이며 이번 문서 갱신에서 실행한 결과가 아니다.

## SD4 후보 기록·부팅

1. `SD4-SHA256SUMS.txt`로 파일을 확인하고 기존 카드 자료를 보관한다.
2. 보드 전원을 끈 뒤 balenaEtcher에서 새 `.img`와 대상 카드를 선택해 기록·검증한다.
   기존 카드 내용은 덮어쓴다. 이미지 파일을 카드의 파일시스템에 복사하는 방식이 아니다.
3. 온보드 TF 슬롯에 SDHC/SDXC 카드를 넣고 전원을 켠다. SPI 모드로 사용한 카드도 전원을 껐다 켜야 한다.
4. Vivado Hardware Manager의 `xc7a200t`에 새 `.bit`를 Program Device로 올린다.
5. UART를 115200 baud, 8N1, 흐름 제어 없음으로 연다. 포트 번호는 PC에서 확인하고 터미널 하나만 사용한다.

JTAG 구성은 휘발성이며 전원을 끄면 다시 올려야 한다. 구성 Flash 기록은 이번 작업 범위가 아니다.
카드 전원 스위치·연결된 card-detect 입력이 확인되지 않아 실행 중 카드 교체를 지원하지 않는다.

OpenSBI·Linux 진행과 `mmcblk0: p1 p2`, `ORYUKDO: SD ext4 /data mounted`를 확인한다.
`/data unavailable` 뒤 복구 셸만 나왔다면 영구 저장 성공이 아니다.

```sh
cat /etc/oryukdo-image
cat /proc/cpuinfo
uname -a
cat /proc/partitions
cat /proc/interrupts
cat /proc/mounts
storage-check
ddrcheck
```

`storage-check`는 실제 ext4 마운트 확인 후 256KiB 쓰기·sync·캐시 비우기·재읽기 해시를 검사한다.
실행 전후 SD 인터럽트 수 증가도 확인한다. `ddrcheck`의 상위 메모리 검사는 전체 1GiB 전수 검사가 아니다.

영구 보존은 별도로 확인한다.

```sh
echo ORYUKDO_SD4_PERSISTENCE > /data/persistence-check.txt
sync
sha256sum /data/persistence-check.txt
cd /
# /data를 사용하는 프로그램을 종료한 뒤 실행한다.
umount /data
```

unmount 성공 후 전원을 껐다 켜고 비트스트림을 다시 올린 뒤 같은 파일·해시를 확인한다.
unmount 실패를 정상 종료로 간주하지 않는다. 세부 절차는 [후보 보드 검사 문서](../variants/sd4-dma/BOARD_STORAGE_CHECK_KO.md)를 따른다.

## 파일시스템·DMA·화면 범위

새 이미지는 263MiB이며 첫 파티션은 raw 부팅 데이터, 두 번째는 256MiB ext4 `/data`다.
Linux 루트는 기존 initramfs이고 BusyBox를 유지한다. SD 파일 저장 경로는 구현됐으나 위 실보드 검증은 남아 있다.
카드의 나머지 용량으로 자동 확장하지 않는다. `/data`가 마운트되지 않은 상태에서 그 디렉터리에 쓰면 영구 저장되지 않는다.

BOSIO 전용 16MiB와 표시 버퍼 8MiB 등 예약 영역 때문에 `MemTotal`은 물리 1GiB와 다르다.
이전 기준본의 `1024148 kB` 값을 새 후보의 기대값으로 사용하지 않는다.
새 DMA의 실제 속도·CPU 사용률을 측정해야 하며 4비트 25MHz의 이론치 12.5MB/s를 실측값으로 쓰지 않는다.

새 이미지에는 BoAYO native-v2가 보존돼 있다. UART 셸 부팅만으로 HDMI 데스크톱을 판정하지 않고,
BOSIO 구동·프레임 게시·실제 영상·키 입력을 확인해야 한다. 이번 저장소 변경은 BoAYO DMA 가속을 포함하지 않는다.
추가 AXI UART·SPI·I2C는 RTL에 있지만 현재 DT에서 자동 Linux 장치 등록을 제공하지 않는다.

## 핀 배치

현재 native SD는 bank16 LVCMOS33, 1.8V 전환 없음이다. 원본은 [SD XDC](../variants/sd4-dma/soc/board/sd.xdc)다.

| 신호 | FPGA 핀 |
|---|---|
| native SD CLK / CMD | B20 / E17 |
| native SD DAT0 / DAT1 / DAT2 / DAT3 | A20 / B21 / F16 / A21 |
| 기본 UART | V18 / V19, 방향은 해당 구성 XDC 참조 |
| 추가 UART TX / RX | Y16 / AA16 |
| 추가 SPI SCK / MOSI / MISO / CS | W15 / W16 / AB16 / AB17 |
| 추가 I2C SCL / SDA | W14 / Y14 |
| 센서 I2C SCL / SDA | AA15 / AB15 |
| HDMI2 clock ± | E19 / D19 |
| HDMI2 data0 ± / data1 ± / data2 ± | F13/F14 / E13/E14 / C18/C19 |

이전 SPI 기준본은 같은 커넥터를 CLK/MOSI/MISO/CS = B20/E17/A20/A21로 사용했다.
그 SPI 명칭을 새 native SD의 DAT1/DAT2 핀 설명으로 대신하면 안 된다.
I2C 외부 모듈에는 적절한 풀업이 필요하다. 보드 모델·커넥터 방향과 제공 XDC를 기준으로 연결한다.

## 이전 기준본에서 실제 확인한 결과

2026-11-08 기준본은 JTAG→SD→OpenSBI→Linux→`oryukdo#` 셸,
산술 결과 42, `6.12.0-oryukdo-kfb`, `DDR_HIGH_OK pages=16`을 확인했다.
이 구성의 SD는 부팅 전용이며 런타임 파일 저장을 지원하지 않았다. 이 기록은 새 후보의 실보드 PASS가 아니다.
