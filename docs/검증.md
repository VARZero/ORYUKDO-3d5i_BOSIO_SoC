# 검증 근거와 미완료 항목

실보드 검증 일시는 2026-11-08 17:33 KST이다. 게시 준비 시 보드를 재설정하거나 UART를 새로 점유하지 않았다.

| 검증 | 근거 / 상태 |
|---|---|
| SD→Linux→쉘 | `evidence/physical_tlb_fix_20261108/boot_uart.txt` |
| 명령 입력·상위 DDR 16페이지 | 같은 폴더의 `trace_review.json` 및 원본 UART |
| 배선 후 타이밍·리소스 | `evidence/board_tlb_v1/physical_acceptance.json`와 `.rpt` |
| 보드 입력 125개 | `provenance/board_sources.json` |
| Linux 소스 대조 | 일반 파일 86,618개, 변경 3개, 추가 0개 |
| 보존된 커널 Image | WSL 실제 진단 빌드와 바이트 일치 |

원본 UART에는 JTAG 재구성 전의 이전 커널 출력도 포함된다. 판정은 마지막 OpenSBI 배너 이후에 한정했다. 타이머 출력이 다른 진단 표시 중간에 끼어든 경우 완전한 타이머 표시만 분리하여 해석했다. 가공본과 원본을 함께 보존한다.

배선 결과는 LUT 108,798, FF 72,969, BRAM 101.5, DSP 62, WNS +0.101ns, WHS +0.023ns, TNS/THS 0이다. 164,661개 net 전부 배선되었다. 주요 경로는 IST `bank_response_valid_reg[5]` → `issue_data_reg[266]`, 데이터 지연 19.322ns이다.

DRC Error/Critical과 CDC Warning/Critical은 0이다. 생성된 MIG 내부의 BUFC-1 4개, REQP-1709 1개는 남아 있다. DRC 전체가 0이라고 설명하지 않는다. Gray 경로 68개와 bus skew 보고서도 보존했다.

## 아직 완료로 판단하지 않는 항목

- 수정 RTL의 SD부터 UART 쉘까지 전체 디지털 콜드 부팅. 기존 실행은 별도로 유지 중이며 이 패키지는 PASS를 주장하지 않는다.
- 스냅샷 이후 2억 사이클 시험은 쉘 이전에 제한에 도달했다. clocksource 이후 타이머 394회 복귀를 확인했지만 쉘 PASS는 아니다.
- 진단 표시를 제거한 일반 Linux 커널의 수정 비트스트림 실보드 재시험.
- 전체 1GiB RAM 전수 검사. 기존 검사는 상위 주소 16페이지이다.
- HDMI 실제 영상, BOSIO의 Linux 드라이버, BoAYO WM, 추가 주변장치의 실제 외부 장치 동작.
- 새 환경에서 전체 펌웨어와 비트스트림을 처음부터 빌드한 바이트 동일성.

이번 정리에서 실행한 소스 일치·이미지 재구성·패치 복원·lint·TLB 검사의 결과는 `evidence/package_checks/`에 별도 저장한다. 기존 합성·배선 보고서를 새로 실행한 결과인 것처럼 표시하지 않는다.
